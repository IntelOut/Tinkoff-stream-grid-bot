# Торговый бот для Тинькофф Инвестиции (Grid Trading)

Асинхронный сеточный торговый бот для Тинькофф Инвестиции с использованием новой библиотеки t-tech-investments.

## Описание стратегии

Сеточная торговля (Grid Trading) - это стратегия, при которой бот выставляет сетку лимитных ордеров выше и ниже текущей цены:
- Ордера на продажу выше текущей цены
- Ордера на покупку ниже текущей цены

При исполнении любого ордера бот автоматически выставляет противоположный ордер на соседнем уровне сетки, поддерживая постоянное количество активных ордеров.

## Возможности

- Асинхронная архитектура для высокой производительности
- Сеточная торговая стратегия
- Автоматическое восстановление ордеров
- SQLite база данных для сохранения состояния
- Поддержка Docker
- Конфигурация через переменные окружения
- Подробное логирование
